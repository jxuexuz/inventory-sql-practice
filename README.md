# 文具店进销存数据与库存核对

这是我面向 ERP 实施助理岗位开展的个人 SQL 模拟实践。我在指导下使用 MySQL 和 DBeaver，练习商品建档、采购入库、销售出库、客户退货、供应商退货和库存核对。数据均为模拟数据，不代表企业项目、实习或真实 ERP 上线经历。

核心成果是一个可追溯到原始出入库记录的库存报表，以及一条客户退货超量检查。整理版根据我完成的第01～10份练习提取，由 AI 协助规范脚本、补充文档与校验；没有把整理协助包装成独立开发经历。

## 先看结果

期初库存为0，客户退货均已验收且可以重新销售。公式为：采购入库 − 销售出库 + 客户退货 − 供应商退货。

| 商品 | 单位 | 入库 | 出库 | 客户退货 | 供应商退货 | 库存 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 中性笔 | 支 | 150 | 50 | 5 | 10 | 95 |
| 笔记本 | 本 | 30 | 8 | 2 | 4 | 20 |
| 文件夹 | 个 | 0 | 0 | 0 | 0 | 0 |
| 订书机 | 台 | 0 | 0 | 0 | 0 | 0 |

现有数据的客户退货超量检查返回0行。模拟“出库30、累计退货35”时，仅该案例被检出，超量5；退货恰好等于出库数量不属于超量。

## 如何复现

目标环境为 MySQL 8.4 和 DBeaver，文件编码 UTF-8。运行者自行配置数据库连接与账号权限，项目不提供账号、密码或连接文件。不需要 Java、Web 服务或外部数据集。

1. 在 DBeaver 连接自己的本地测试 MySQL，先运行 `SELECT VERSION();` 确认版本。请勿在生产环境操作。
2. 检查 `SHOW DATABASES LIKE 'inventory_portfolio_demo';` 应返回0行。若已有同名库，停止，先核实用途；可以把所有脚本里的库名统一改成一个未使用的新名称。不要删除已有数据库。
3. 打开 `sql/01_schema.sql`。先单独执行 `CREATE DATABASE`，成功后执行剩余建表语句。遇到任何错误立即停止。本步骤仅初始化一次，不是可重复执行的迁移脚本。
4. 打开 `sql/02_seed.sql`。先执行 `USE`、`START TRANSACTION` 和全部 INSERT；确认没有错误后执行 `COMMIT`。若任何 INSERT 失败，执行 `ROLLBACK;` 并排查，不要忽略报错继续提交。初始行数依次应为4、3、3、2、2。
5. 执行 `sql/03_inventory_report.sql`，核对上面的4行报表。
6. 执行 `sql/04_customer_return_check.sql`，应返回0行；执行 `sql/05_boundary_tests.sql`，应返回1行超量5。
7. 可选执行 `sql/06_learning_comparisons.sql`，理解筛选和关联重复。每条语句前的注释说明了预期结果。

01、02会写入新的演示库，**只运行一次**；03～06为只读查询，可以重复运行。每份文件都含 `USE`，重新连接后先执行它，再选中完整查询执行。不要把所有文件反复整批执行。原来的 `inventory_practice` 库不受本项目脚本影响。

## 验证状态

原练习已在学习者的 MySQL 环境执行，截图展示最终库存95、20、0、0及退货边界结果。2026年9月20日，AI协助在独立的 MySQL 8.4.11 临时实例中从头执行了整理版01～06脚本，核对报表、退货检查、边界结果和数据行数，结果符合预期；并验证累计多次退货、主键、外键及零数量拒绝。测试实例关闭网络，未使用学习者原数据库，已在测试后停止。详见[验证记录](docs/05_verification.md)。学习者仍需亲自复跑并讲解，不能把自动检查说成自己独立完成。

另外提供 `tools/check_portable.py` 做独立的 SQLite 内存逻辑检查。该检查会去掉 MySQL 的选库语句并转换事务开头，**不等同于 MySQL 实测**，不能替代目标数据库验收。

可选逻辑检查需 Python 3，仅使用标准库；在项目根目录运行 `python tools/check_portable.py`。它不连接 MySQL、不读取密码，也不修改数据库文件。

## 项目边界

项目没有用户界面、权限审批、价格金额、库存成本、期初导入、多仓、批次、并发控制和上线部署。客户退货超量查询属于事后检测，不会自动拒绝异常写入；尚未实现供应商退货超量检查或防止销售超库存。外键仅保证原记录存在，正数约束仅保证数量大于0。

公开展示时只上传本项目目录，不上传本机 DBeaver 工作区、数据库备份、个人简历或含账号信息的截图。当前未发布到 GitHub。
