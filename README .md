## 项目简介

这是我面向 **ERP 实施助理岗位**开展的个人 SQL 模拟实践。在指导下使用 MySQL 和 DBeaver，练习：

- 商品建档与基础资料维护
- 采购入库、销售出库
- 客户退货（已验收、可重新销售）、供应商退货
- 库存结存计算与核对
- 一条业务规则校验：客户累计退货不得超过累计出库

数据均为**模拟数据**，不代表任何真实企业项目、实习经历或真实 ERP 上线过程。

**核心成果**：

1. 一张可追溯到原始出入库记录的库存结存报表；
2. 一条客户退货超量检查语句；
3. 一组边界测试，验证"退货等于出库不算超量、退货超过出库才算超量"。

---

## 业务场景与核心公式

- 期初库存为 **0**；
- 客户退货在本项目中**均已验收入库**，可以再次销售，因此加回库存；
- 供应商退货属于把货退回供应商，因此从库存中扣减；
- 库存计算公式：

  ```
  期末库存 = 采购入库 − 销售出库 + 客户退货 − 供应商退货
  ```

四个商品：中性笔、笔记本、文件夹、订书机。不同单位（支/本/个/台）**不汇总成"总库存"**。

## 先看结果

期初库存为 0，客户退货均已验收且可以重新销售。公式为：采购入库 − 销售出库 + 客户退货 − 供应商退货。

| 商品 | 单位 | 入库 | 出库 | 客户退货 | 供应商退货 | 库存 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 中性笔 | 支 | 150 | 50 | 5 | 10 | **95** |
| 笔记本 | 本 | 30 | 8 | 2 | 4 | **20** |
| 文件夹 | 个 | 0 | 0 | 0 | 0 | **0** |
| 订书机 | 台 | 0 | 0 | 0 | 0 | **0** |

## 异常检查说明

- 现有数据下，客户退货超量检查应返回 **0 行**（无异常）；
- 模拟"出库 30、累计退货 35"时，仅该案例被检出，**超量 5**；
- **退货数量恰好等于出库数量不属于超量**——这是边界条件，必须用测试固定下来。

## 如何复现

> 目标环境：MySQL 8.4 + DBeaver，UTF-8。01、02 会写入新的演示库 `inventory_portfolio_demo`，**只运行一次**；03～06 为只读查询，可反复运行。

1. 在 DBeaver 连接自己的本地测试 MySQL，先运行 `SELECT VERSION();` 确认版本。**请勿在生产环境操作。**
2. 检查是否已有同名库：

   ```sql
   SHOW DATABASES LIKE 'inventory_portfolio_demo';
   ```

   应返回 0 行。若已有同名库，**停止并先核实用途**；可以把所有脚本里的库名统一改成一个未使用的新名称。**不要删除已有数据库。**
3. 打开 `sql/01_schema.sql`。先单独执行 `CREATE DATABASE`，成功后再执行剩余建表语句。遇到任何错误立即停止。本步骤仅初始化一次，**不是可重复执行的迁移脚本**。
4. 打开 `sql/02_seed.sql`。先执行 `USE`、`START TRANSACTION` 和全部 `INSERT`；确认没有错误后执行 `COMMIT`。若任何 `INSERT` 失败，执行 `ROLLBACK` 并排查，**不要忽略报错继续提交**。初始行数依次应为 4、3、3、2、2。
5. 执行 `sql/03_inventory_report.sql`，核对上面 4 行报表。
6. 执行 `sql/04_customer_return_check.sql`，应返回 **0 行**；执行 `sql/05_boundary_tests.sql`，应返回 **1 行超量 5**。
7. 可选执行 `sql/06_learning_comparisons.sql`，理解筛选和 JOIN 的重复行问题。每条语句前的注释都写明了预期结果。

> 原有的 `inventory_practice` 库不受本项目脚本影响。

## 学习要点

这个小项目我重点练到的点：

- **库存口径**：为什么客户退货加回、供应商退货扣减，而不是笼统"退货就减库存"；
- **聚合粒度**：不同单位的商品不能 SUM 成一个"总库存"；
- **边界条件**：等于不算超量，大于才算，必须用测试固定；
- **事务**：seed 数据用 `START TRANSACTION / COMMIT / ROLLBACK`，失败不半路提交；
- **只读与写入分离**：建库、建表、灌数只跑一次，查询可以反复跑；
- **可复现**：每一步都写清预期返回几行，而不是"跑一下看看"。
